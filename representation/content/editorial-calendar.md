## §1 — Universal cadence concept

**The principal-grade dev/editorial publication's cadence shape balances quality bar against publication velocity.** Cadence too slow loses momentum + discoverability flywheel; cadence too fast burns the writer + erodes quality. The marriage is sustainable density — predictable thematic anchors that shape the writer's week without rigidity, with weekend recovery built into the cadence at construction.

**Examples that prove the concept at world-class scale:**

- **Stratechery (Ben Thompson)** — weekly Tuesday free article + 3 paid daily updates per week + Sharp Tech podcast + Sharp China podcast. Hybrid-cadence proven at solo-author principal-grade across 12+ years.
- **Bytes by ByteByteGo** — weekday-daily cadence at solo-author scale; tightly themed dev-content; sustainable via newsletter-first model.
- **Stripe Press** — irregular cadence; long-form when ready; quality > frequency. Tentpole-piece register; not the right shape for traction-mode unknown brand.
- **The Pudding** — irregular cadence; per-article-as-designed-object; principal-grade craft; not a velocity-target match for V1 traction.
- **NYT Magazine** — weekly print + daily digital; institutional-team cadence inappropriate for solo-dev modeling.

**Prime's expression — Stratechery-shaped hybrid for V1 unknown-brand traction posture** (Mayor 2026-05-09 council adjudication):

5/7 days posting; thematic anchors per day (NOT theme-locked content); Sat/Sun dark by default; weekly long-form NARRATIVE Monday + 4 mid-weight days + lightweight Friday retrospective. Solo-dev sustainable; Claude co-author multiplies time-budget per article; crossfire mechanism amplifies discoverability per `cd7-content-pipeline-stack.md` §11.

## §3 — Sustainability discipline

Per `feedback_subscription_flat_cost_model.md` solo-dev team-of-1-for-~2-years operational baseline + research evidence (daily.dev: 83% developer burnout; "publishing less, but more consistently, almost always outperforms short bursts").

### §3.1 — Time-budget per content-day (1-2 hour daily window non-negotiable)

| Output type | Target time | AI-multiplier source |
|---|---|---|
| Monday NARRATIVE long-form | 90-120 min | Claude draft + Mayor voice-overlay edit; Adobe Firefly cover image; Beehiiv compose |
| Tue/Thu META article | 30-45 min | Claude generates from commit-log + agent telemetry; Mayor edits + verifies |
| Wednesday NARRATIVE process-piece | 60-90 min | Claude transcript-extract from Mayor-Claude conversation + voice-overlay |
| Friday lightweight retrospective | 20-30 min | Claude summarizes week's commits + LiveTicker; Mayor adds Mayor-voice retrospective |
| Multimedia (cover + 1-2 inline) | 10-15 min | Adobe Firefly + Recraft batch generation |
| Cross-post variant generation | 10-15 min | n8n + Claude API automated reshape per platform |
| Distribution scheduling | 5 min | Croissant for social trio; n8n for dev platforms |

**Daily total: ~2 hours typical; 2.5-3 hours on Monday (long-form day).**

### §3.2 — Weekend recovery

Sat/Sun dark **by default**. LiveTicker continues surfacing autonomous activity (commits / agent dispatches / cd-ledger entries) — mechanical signal that DISpatch is alive without Mayor authoring. This is sustainability-protected: no published-articles obligation Sat/Sun.

Exception: if a major shipped milestone lands Sat/Sun, Mayor can ship a META dispatch — but it's optional, not obligatory.

### §3.3 — Drift indicators (gate-not-target per `feedback_metric_vs_gate_discipline.md`)

If any of these surface, cadence shape is failing and warrants amendment-cycle review:

- Daily time-budget regularly exceeds 2.5 hours (signal: AI-multiplier breakdown OR scope-creep per article)
- Weekend dark-discipline broken 3+ weekends in a quarter (signal: cadence not sustainable; pull back)
- Quality drift visible in 3+ consecutive articles (signal: Claude co-author register slipping; voice-overlay needed harder)
- Crossfire variant generation taking >20 min/day (signal: n8n workflow needs optimization)

Drift triggers `feedback_documentation_lifecycle.md` amend cycle; calendar shape refinable per evidence.
